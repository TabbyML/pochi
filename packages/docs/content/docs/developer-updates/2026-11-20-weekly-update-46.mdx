# Weekly Update #46: Workflow improvements in Pochi 0.84

### TL;DR

This week’s update focuses on two improvements to everyday workflows: checking on a running background subagent and trying a different direction in a conversation without changing your files.

[Pochi 0.84](https://github.com/TabbyML/pochi/releases/tag/vscode%400.84.0) also ships the clickable task transcript badge and the removal of the separate Plan mode, both previewed [last week](./2026-11-13-weekly-update-45).

### ✨ Enhancements

- **Check on a background subagent before it finishes:** When Pochi starts a background subagent, the parent agent gets a link to a transcript that updates after each step. Ask what the subagent has checked so far without waiting for its final result. [**#2084**](https://github.com/TabbyML/pochi/pull/2084)

- **Fork a conversation without changing your files:** Use **Fork** between two messages to try a different direction in a new task. The fork copies the conversation up to that point and leaves your workspace as it is. It no longer restores a file checkpoint. [**#2082**](https://github.com/TabbyML/pochi/pull/2082)
